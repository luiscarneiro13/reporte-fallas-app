# IronFlow Project Analysis

- **Type**: React Native mobile application
- **Framework**: Expo SDK 54
- **Language**: JavaScript/TypeScript
- **Key Features**:
  - Firebase integration (messaging, app services)
  - React Navigation for screen routing
  - Zustand for state management
  - Role‑based screens (Operator, Supervisor, Admin)
  - Comprehensive Jest testing
- **Directory Structure**:
  - \`src/api/\` – API clients and services
  - \`src/components/\` – reusable UI components
  - \`src/screens/\` – screen implementations
  - \`src/store/\` – Zustand stores
- **Development Workflow**:
  - Docker‑based environment
  - Expo development server with hot reload
  - Scripts for testing, building, and validating releases
